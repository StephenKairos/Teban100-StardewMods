# Release notes
## Upcoming release
* Updated for Stardew Valley 1.3 – 1.6.16.
* Added update keys.
* Rope Bridge downloads are now created via [automated and attested builds](https://www.patreon.com/posts/automated-builds-148417912).  
  _This guarantees that the download only contains what's in the public source code and hasn't been tampered with._
* Embedded `.pdb` data into the DLL, which fixes error line numbers in Linux/macOS logs.
* Fixed ladders dropped by a monster or placed with a staircase not immediately passable.
* Internal refactoring to simplify maintenance.
